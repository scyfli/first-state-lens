Property Reassessment · Kent County, Delaware

What Kent County assessed its property at

After Kent County's 2024 reassessment — the first countywide revaluation in decades — every parcel got a new assessed value based on current market value. This shows those values in aggregate: the typical assessment, the total on the roll, and the breakdown by property type. Pulled directly from the county's public parcel records.

How to read this. These are assessed market values from Kent County's public parcel records — not tax bills. First State Lens does not compute, estimate, or display anyone's taxes. Property tax depends on rates that the county, municipalities, school districts, and vo-tech districts each set separately. After the 2024 reassessment, Kent County rolled its own rate down from 36¢ to 5.72¢ per $100 of value, so a higher assessed value does not translate one-to-one into a higher bill. A reassessment also updates every property at once, so how any single bill changes depends on how that property's value moved relative to others and on the rates each body sets. Because the reassessment replaced a decades-old assessment basis with current market value, these figures are not comparable to the old assessed values — we show no before-and-after. We publish aggregates only: no owner names, no individual parcels. This dashboard covers Kent County only — New Castle and Sussex are not included here (their comparable public data is access-pending). First State Lens adds no commentary.
