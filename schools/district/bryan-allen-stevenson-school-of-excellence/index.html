Enrollment, test scores, chronic absenteeism, graduation and teacher salaries for Bryan Allen Stevenson School of Excellence, from the Delaware Department of Education's public data, with the statewide figure beside each one.

How to read this. Every figure on this page comes from the Delaware Department of Education's public data on data.delaware.gov, and each one carries its own school year, because the state publishes the measures at different times. Proficiency is from the Smarter Balanced Summative Assessment, the statewide test for grades 3 to 8, for all students; it is not mixed with the SAT or the alternate assessment, so an LEA that serves only high school grades has no proficiency figure. We use only rows the state marks REPORTED. Where the state suppresses a value to protect student privacy, or publishes none, this page says "Not reported". It never shows a zero in its place. The statewide figure sits beside each measure for context only. We rank no school or district and draw no conclusions about Bryan Allen Stevenson School of Excellence. The state is the authority: if this page and the Delaware Report Card differ, the state is right and we fix this page.
