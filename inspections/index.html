Delaware restaurant inspections

Updated October 14, 2026

What state food inspectors recorded at restaurants, markets, cafeterias and other food establishments, by establishment and date, in the state's own words.

How to read this. Each entry is a violation recorded at a state food inspection, in the state's own words, as the Delaware Division of Public Health, Office of Food Protection published it. A violation is not a closure. The state says many violations can be corrected on the spot during the inspection, and its inspection report marks those, but the public data file does not say which ones were, so this page cannot show that. We give no grades or scores and do not rank or label any establishment. Establishments are listed A to Z and inspections by date, newest first. This is the record as the state published it: if this page and the state's record differ, the state is right and we fix this page. The state's inspection FAQ explains the categories of violations and when a restaurant is closed.

What the state's file shows

STATE DATA AS OF OCTOBER 9, 2026

The file lists 9,137 inspections at 3,716 food establishments in 55 towns, dated October 1, 2024 to October 7, 2026. The state publishes it weekly and keeps about the past two years. This page shows inspections from the 3 years before the state's last update. Every inspection in the file falls inside that window.

Source: Delaware Division of Public Health, Office of Food Protection, Food Establishment Inspection Violations (data.delaware.gov, dataset 384s-wygj), as updated by the state on October 9, 2026.

    About this data

    • Nearly every row in the state's file is one violation at one inspection: the business name, street address, city and ZIP as the state lists them, the inspection date, the inspection type, and the violation code and description. We show those words as the state wrote them.
    • For mobile food units (food trucks, trailers and carts, which the state marks "MOB"), we show the town only. The street address the state lists for a mobile unit can be the operator's home, so we leave it out.
    • The inspection types in the file are Complaint, Follow-up and Routine. A follow-up inspection is a return visit; the state says inspectors return within 10 days when a problem needs more time to fix.
    • The file is a list of violations. An inspection that found no violation usually does not appear at all, so a missing establishment or date does not mean no inspection took place. Some inspections are listed with no violation; we show those as "No violation listed".
    • The file has no field saying whether a violation was corrected during the inspection, and no field for the kind of establishment. We do not add either.
    • Business names appear exactly as the state's file spells them, including notes such as "(Closed)". The file does not say what such a note means for a given business.
    • We give no grades or scores, count nothing per establishment, and order only by name and date.
    • 10 rows in the state's file carry inspection dates after the state's own last update (November 2026, December 2026). An inspection cannot be dated in the future, so we leave those rows out until the state's file changes.
    • Questions about a specific inspection report go to the Office of Food Protection at 302-744-4546, the number the state lists with the data.

    Sources: Food Establishment Inspection Violations, data.delaware.gov; Food Establishment Inspection FAQ, Delaware Division of Public Health.
